#### a. ตัวอย่าง C# ที่อยู่ในกลุ่ม Utility Class
Class ที่เลือกคือ Registry ซึ่งมีการจัดเตรียม Objects เพื่อ Represent Root Key ใน Windows Registry และมี Static Methods เพื่อเข้าถึงคู่ของ Key-Value นั้น ๆ

```c#
public static class Registry
```

Static Method ที่เลือกคือ GetValue() ซึ่งต้องการ Parameters จำนวน 3 ตัวได้แก่ keyName (String), valueName (String) และ defaultValue (Object) ซึ่งจะ Return เป็น null ถ้า subkey ที่ระบุโดย keyName ไม่มีอยู่จริง
นอกนั้นจะ Return ค่า ที่ผูกกับ valueName หรือ defaultValue ถ้าหา valueName ไม่เจอ 
```c#
public static object? GetValue(string keyName, string? valueName, object? defaultValue);
```


วิธีการเรียกใช้
```c#
using System;
using Microsoft.Win32;

public class Example
{
    public static void Main()
    {
        const string userRoot = "HKEY_CURRENT_USER";
        const string subkey = "RegistrySetValueExample";
        const string keyName = userRoot + "\\" + subkey;

        Registry.SetValue(keyName, "", 5280);
        int tInteger = (int) Registry.GetValue(keyName, "", -1);
        Console.WriteLine("(Default): {0}", tInteger);
        // (Default): 5280
    }
}
```

จากตัวอย่างจะเห็นว่าเราสามารถเรียกชื่อ Class แล้วตามด้วยชื่อ Method ได้ในทันทีโดยไม่จำเป็นต้องสั่ง new Registry() ก่อนหมายความว่า Method นี้ไม่ผูกติดกับ Object ใด ๆ 
เลยจึงเป็น Utility Class

#### b. ตัวอย่าง C# ที่อยู่ในกลุ่ม Mutable Class
Class ที่เลือกคือ StringBuilder เป็น Class ที่สามารถเปลี่ยนแปลง Characters ใน String ได้โดยตรง

```c#
public sealed class StringBuilder : System.Runtime.Serialization.ISerializable
```

วิธีการเรียกใช้

```c#
using System;
using System.Text;

public sealed class App
{
    static void Main()
    {
        StringBuilder sb = new StringBuilder("ABC", 50);
        // Append three characters (D, E, and F) to the end of the StringBuilder.
        sb.Append(new char[] { 'D', 'E', 'F' });
        // Append a format string to the end of the StringBuilder.
        sb.AppendFormat("GHI{0}{1}", 'J', 'k');
        // Display the number of characters in the StringBuilder and its string.
        Console.WriteLine("{0} chars: {1}", sb.Length, sb.ToString());
        // Output: 11 chars: ABCDEFGHIJk
    }
}
```

เดิมทีหากเป็น String ปกติเราจะไม่สามารถแก้ไข String ตัวเดิมได้เลยจะต้องไปสร้าง Object ตัวใหม่แทน แต่ในกรณีนี้เราสามารถ New StringBuilder() โดยระบุ String เริ่มต้นมาก่อน จากนั้นเราสามารถดำเนินการ
แบบ Mutable ผ่าน Variable ที่ Reference ไปยัง Object ตัวนั้นตอนสั่ง New ทำให้สามารถแก้ไขค่าต่าง ๆ ได้ภายใน Object ตัวเดิม

#### c. ตัวอย่าง C# ที่อยู่ในกลุ่ม Immutable Class
Class ที่เลือกคือ Uri เป็น Class ที่จัดเตรียม Object เพื่อ Representation และอำนวยความสะดวกในการ Access Uniform Resource Identifier (URI)

```c#
public class Uri : IEquatable<Uri>, ISpanFormattable, System.Runtime.Serialization.ISerializable
```

วิธีการใช้

```c#
Uri uri = new Uri("https://user:password@www.contoso.com:80/Home/Index.htm?q1=v1&q2=v2#FragmentName");

Console.WriteLine($"AbsolutePath: {uri.AbsolutePath}");
Console.WriteLine($"AbsoluteUri: {uri.AbsoluteUri}");
Console.WriteLine($"DnsSafeHost: {uri.DnsSafeHost}");
Console.WriteLine($"Fragment: {uri.Fragment}");
Console.WriteLine($"Host: {uri.Host}");
Console.WriteLine($"HostNameType: {uri.HostNameType}");
Console.WriteLine($"IdnHost: {uri.IdnHost}");
Console.WriteLine($"IsAbsoluteUri: {uri.IsAbsoluteUri}");
Console.WriteLine($"IsDefaultPort: {uri.IsDefaultPort}");
Console.WriteLine($"IsFile: {uri.IsFile}");
Console.WriteLine($"IsLoopback: {uri.IsLoopback}");
Console.WriteLine($"IsUnc: {uri.IsUnc}");
Console.WriteLine($"LocalPath: {uri.LocalPath}");
Console.WriteLine($"OriginalString: {uri.OriginalString}");
Console.WriteLine($"PathAndQuery: {uri.PathAndQuery}");
Console.WriteLine($"Port: {uri.Port}");
Console.WriteLine($"Query: {uri.Query}");
Console.WriteLine($"Scheme: {uri.Scheme}");

// AbsolutePath: /Home/Index.htm
// AbsoluteUri: https://user:password@www.contoso.com:80/Home/Index.htm?q1=v1&q2=v2#FragmentName

// Port: 80
// Query: ?q1=v1&q2=v2
```

จากตัวอย่างข้างต้นเราจะเห็นว่าเมื่อเราสร้าง Object มาแล้ว ใส่ URI ลงไป สิ่งที่เราทำได้หลังจากนี้คือการ Get ค่าออกมาได้เพียงอย่างเดียวเท่านั้น เราไม่สามารถที่จะ Set ค่าใหม่ลงไปบน Object ตัวเดิมได้
และหากอ้างอิงจากตาราง Property จะเห็นว่าเราทำได้เพียง Get ค่าออกมาเท่านั้น
